# Tick 0162 Capability Rave

## Fast-Malleable Items

1. `agent evidence-receipt`: can already hash real paper artifacts; unlocks paper QA as reusable evidence instead of tick prose.
2. `agent task-create`: can wrap paper generation as a lifecycle task; unlocks interop-shaped audit records.
3. `agent task-transition`: can require passing evidence before success; unlocks explicit stop/go state.
4. `agent task-export`: can emit MCP/A2A-shaped payloads; unlocks future external reviewer/runner integration.
5. `research paper-index`: can surface task envelope status if task artifacts become standard.
6. `paper-runner-record`: can become the bridge between research provenance and generic evidence receipts.
7. `manifest-verify`: can eventually require task receipts for golden packets.
8. `paper-qa`: can produce pass evidence for task success.
9. `repair-plan`: can consume failed evidence receipts instead of parsing only manifest failures.
10. `.loop-memory/actual-nhanes/papers/*`: already has stable per-paper directories; unlocks repeatable task folders.

## Looks Fixed But Is Not

1. Runner status looks fixed, but retrospective downgrade proves status needs binding context.
2. Paper QA looks fixed, but it is reporting QA, not methods adequacy.
3. AnalysisSpec looks fixed, but some papers bind retrospectively.
4. Task envelopes look generic, but need real research artifacts to reveal missing fields.
5. Evidence receipts look generic, but need validator-specific semantics.
6. Paper index looks complete, but task lifecycle is invisible.
7. Reproducibility looks hash-backed, but not necessarily spec-governed.
8. Cost boundary looks declared, but local runs rarely record actual elapsed/resource cost.
9. Share safety looks separable, but paper folders still contain absolute local paths.
10. Research questions look varied, but most are still single-exposure/single-outcome regression papers.

## Selected Move

Dogfood the agent interop layer on the BMI/HbA1c paper by creating evidence receipts, task lifecycle artifacts, and MCP/A2A exports. This is a small artifact-only move with high leverage because it tests the generic Agenteer layer against a real research output.
