# Tick 0324 Capability Rave - Trust-Layer Hardening Surface

## Ten Fast-Malleable Items

1. `collectEstimateLikeRecords`: recognize diagnostic metrics as estimates; unlocks correct QA for sensitivity/specificity packets.
2. `detectRunSummary`: derive model family from explicit `method` before raw-text search; avoids accidental `linear` matches.
3. `refsForExisting`: use artifact source maps; already improved by tick 0323.
4. `renderManuscriptMarkdown`: add route-specific results paragraphs; improves reader usefulness without new commands.
5. `scoreInspection`: weight method blockers more heavily than missing optional lifecycle artifacts.
6. `discoverRunDirs`: collapse child run dirs under packet roots; avoids duplicate benchmark cases.
7. `extractCost`: read dataset-run cumulative ledgers; improves cost audit.
8. `containsUnsupportedCausalClaim`: expand safe negation windows; reduces false positive claim QA.
9. `researchExplorePlanCommand`: write spec-only output option later if repeated need appears.
10. `buildManuscriptQa`: add table/figure expectation checks only when artifact expectations declare them.

## Ten Looks-Fixed-But-Is-Not Items

1. Method QA has “effect-size” checks, but diagnostic accuracy lacked estimate recognition.
2. Unified inspection sees nested files, but benchmark discovery may double-count nested cases.
3. Manuscript generation is structured, but result extraction is still generic.
4. Run readiness is unified, but lifecycle state is still missing for stats-only packets.
5. Benchmark suite scores are useful, but expected failures are not yet per-case declared.
6. Exploration plans generate AnalysisSpec V2 drafts, but covariates still need stronger derivation.
7. Semantic plausibility detection catches sparse/coding text, but it is not dataset-registry-driven yet.
8. Survey checks detect declared specs, but not undeclared survey-shaped variables in arbitrary packets.
9. Cost extraction works for simple receipts, but not all ledger shapes.
10. Reader-facing jargon checks are deterministic, but readability is still only basic.

## Gaps That Should Be Malleable

- The trust layer should normalize route families before running route-specific QA.
- Benchmark cases should have declared expectations instead of one global scoring rule.
- Manuscript generation should eventually consume route-specific renderers from stats/ML/dataset runners.

## Picked Item

Implemented item 1: diagnostic performance metrics now count as estimate evidence in method QA.
