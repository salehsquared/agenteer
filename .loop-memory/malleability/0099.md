# Tick 0099 Capability Rave

## Ten Fast-Malleable Items

1. `researchExportPacketCommand`: can add an export receipt with hashes and local-path scan.
2. `ResearchPacketExport`: can separate local execution refs from shareable export refs.
3. `RESEARCH_EXTRA_ARTIFACTS`: can classify artifacts as local-only, shareable, or derived-redacted.
4. `packet-readiness`: can use export receipt status to set share posture.
5. `artifact-manifest`: can grow an `artifactClass` field without changing file hashes.
6. `data-access-redacted.json`: can become the export substitute for `data-access.json`.
7. `ro-crate-metadata.json`: can cite redacted evidence as a derived entity.
8. `provenance.json`: can model `data-access-redact` as an activity.
9. CLI help: can expose export safety with one command line.
10. Tests: can create a local-path fixture and prove export catches it.

## Ten Looks-Fixed-But-Is-Not Items

1. Export format: looks like a file copy, but can become a policy-mediated copy.
2. Export record: looks like operational metadata, but should be split into local receipt and share receipt.
3. Packet artifact allowlist: looks static, but should be artifact-class metadata.
4. Data-access manifest: looks required for rerunability, but can be local-only.
5. Artifact manifest: looks sufficient, but does not prove share-safety.
6. Packet readiness: looks review-focused, but already owns share posture and can incorporate export receipt.
7. RO-Crate: looks optional, but can carry minimal derived-artifact relationships.
8. Absolute path scan: looks security-only, but also improves portability and reproducibility.
9. NHANES public data: looks non-sensitive, but local path/environment leakage still matters.
10. Export tests: look file-copy based, but can become policy tests.

## Gaps That Should Be Malleable But Are Not Yet

- There is no artifact-class registry.
- Export cannot yet substitute redacted artifacts for local-only artifacts.
- Export record currently conflates local source/output paths with shareable metadata.
- Artifact manifest is packet-local, not export-local.
- No command verifies a completed export independently.

## Picked Item

Picked for the next standard tick: add an export receipt/local-path scan first, then use it in packet readiness. This is the smallest measurable step before changing the export copy policy.
