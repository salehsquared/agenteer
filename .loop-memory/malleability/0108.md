# Tick 0108 Capability Rave

## Ten Fast-Malleable Items

1. Paper artifacts can be packet-local outputs, not only final prose.
2. `analysis.json` can become the evidence source for paper generation.
3. `qa.json` can become a machine-readable paper gate.
4. `critique.md` can become a required human-in-the-loop artifact.
5. Cohort-feasibility artifacts can feed sample construction tables.
6. Web source intake can feed reference sections.
7. Existing report-review checks can be adapted into stricter paper QA.
8. Approximate models can be labeled in a `modelLimitations` field.
9. Paper ideas can be diversified by domain, endpoint type, and estimand.
10. Export receipts can later include paper/QA artifacts.

## Ten Looks-Fixed-But-Is-Not Items

1. A "report" can be a paper if it has abstract/methods/results/limitations.
2. A QA pass can be deterministic before model critique.
3. A critique can be stored as an artifact, not only chat text.
4. References can be structured and reused.
5. Missingness can be paper-specific by variable role.
6. Survey limitations can be standardized without claiming full survey support.
7. Actual analyses can be approximate but clearly labeled.
8. Paper diversity can be scheduled, not accidental.
9. QA can block causal language.
10. Paper generation can reveal new Agenteer primitives.

## Picked Item

Generated the first actual NHANES paper as a packet artifact with `analysis.json`, `paper.md`, `qa.json`, and `critique.md`.
