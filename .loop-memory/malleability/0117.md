# Tick 0117 Capability Rave

## Ten Fast-Malleable Items

1. `research paper-qa`: add a numeric consistency check between reported OR/CI/p values and `analysis.json`.
2. `research paper-qa`: surface check categories in JSON so downstream reports can distinguish reporting, model, threshold, and safety checks.
3. Paper generation scripts: standardize `modelAudit` blocks in `analysis.json`.
4. `.loop-memory/actual-nhanes/papers/*/critique.md`: add a shared critique rubric heading set.
5. `research table-summary`: emit candidate variable roles based on column names and missingness.
6. `research question-bank`: add a "measurement-risk" tag so generated questions intentionally stress thresholds, ratios, missingness, and subsamples.
7. `research paper-qa`: require a rejected-endpoint rationale when evidence contains `discardedEndpoint`.
8. `research paper-qa`: downgrade some style checks to warning so critical status reflects scientific safety rather than document completeness.
9. `research improvement-agenda`: include actual paper QA failures as candidate improvement inputs.
10. `research claim-guard`: reuse paper QA diagnostic-overclaim patterns.

## Ten Looks-Fixed-But-Is-Not Items

1. Papers pass QA, but the QA does not verify numeric results against evidence.
2. Papers cite URLs, but source relevance is not checked.
3. Evidence has row counts, but row-count lineage from merged files is not normalized.
4. Papers mention approximate variance, but the code cannot yet compute design-correct NHANES variance.
5. Covariates are disclosed broadly, but omitted-confounder rationale is not structured.
6. Threshold caveats exist, but threshold source URLs are not bound to specific threshold definitions.
7. Critiques exist, but they are free-form and difficult to compare across papers.
8. Paper directories are well organized, but no index file lists all generated papers and QA status.
9. Web search happens in ticks, but source findings are not automatically attached to paper packet artifacts.
10. The CLI can QA papers, but it cannot yet generate a paper from a structured `analysis.json` contract.

## Gaps That Should Be Malleable But Are Not

- Design-correct NHANES variance remains outside Agenteer.
- Model metadata is inferred from loose `analysis.json` shapes rather than a formal `AnalysisSpec`/`ModelAudit` schema.
- Paper critique is still authored manually by the orchestrating agent, not executed as a deterministic or rubric-based CLI command.

## Picked Move

Schedule a numeric consistency check for tick 0118: parse reported odds ratios, mean differences, confidence intervals, and p-values from paper prose and compare them against evidence JSON with a tolerance. This is higher leverage than adding new prose requirements because it can catch fabricated or stale Results text.
