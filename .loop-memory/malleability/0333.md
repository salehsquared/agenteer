# Tick 0333 Capability Rave - Trust Layer Is More Malleable Than It Looks

## Ten Fast-Malleable Items

1. `collectIssueRecords`: string warnings can become issue records; unlocks runner-warning visibility.
2. `detectRunSummary`: model-specific `n/events/predictors` can replace generic nested counts; unlocks denominator honesty.
3. `detectedModelFamilies`: coefficient shapes can imply model family; unlocks route-specific diagnostics.
4. `semantic_plausibility`: runner warnings can map to semantic/phenotype review; unlocks dataset-specific caution.
5. `renderManuscriptMarkdown`: internal statuses can be translated to reader language; unlocks manuscript QA pass.
6. `benchmark-suite-run`: packet discovery can collapse child runs; unlocks cleaner packet benchmarks.
7. `run-inspect`: next action can prioritize the most important warning; unlocks one-screen review.
8. `method-qa`: warning severities can become route- and dataset-aware; unlocks fewer false alarms.
9. `analysis-results.json` parsing: MIMIC model fields are structured enough for richer diagnostics; unlocks reusable dataset runner promotion.
10. Study-series folders: one-off outputs can be converted into a command contract; unlocks future `dataset-run inspect`.

## Ten Looks-Fixed-But-Is-Not Items

1. Original MIMIC QA pass looks final, but trust-layer warnings show missing diagnostics.
2. Manuscript QA pass looks sufficient, but it can still be generic and should improve scientific structure.
3. Large cohort size looks reassuring, but model denominator may be much smaller.
4. ICD verification looks complete, but phenotype breadth still needs sensitivity contracts.
5. Complete-case analysis looks simple, but missingness mechanism is unreviewed.
6. Cost receipts look robust, but runner promotion needs cost propagation into lifecycle/index views.
7. Row-cache cleanup looks safe, but export/share policies still need packet-level enforcement.
8. Method QA looks generic, but route-specific applicability is still evolving.
9. Existing packets look reproducible, but most lack rerun stability receipts.
10. Study notes look useful, but without a command they remain manual memory artifacts.

## Gaps That Should Be Malleable But Are Not Yet

- MIMIC runner diagnostics are generated by loop-memory Python, not a first-class Agenteer command.
- Phenotype sensitivity plans are prose, not executable specs.
- Dataset-derived table profiling is not attached as a typed artifact.
- MIMIC packet lifecycle/indexing is not yet unified like NHANES paper lifecycle.

Implemented item 1 and strengthened item 4: runner `qa.json` string warnings now surface as method-QA issue evidence, and semantic plausibility recognizes unprofiled required tables / diagnosis-code timing warnings.
