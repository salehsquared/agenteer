# Tick 0076 Cross-Domain Transfer

## Open Question

How can readiness profile naming avoid becoming a false certification signal?

## Fields Searched

- Cartography: map legends / map keys.
- Aviation: NOTAM safety notices.
- Legal discovery: privilege logs.

## Techniques Considered

- Map legend: always expose how symbols should be interpreted.
- NOTAM: operational notice for conditions that affect safe operation.
- Privilege log: structured explanation for withheld information.

## Chosen Citation

Map legend / key: cartography guidance says legends explain symbols and prevent misinterpretation. Search source used: https://mapular.com/glossary/map-legend

## Structural Mapping

- Map symbols = readiness profile/status/posture fields.
- Map legend = profile caveat.
- Misread map = treating readiness profile as statistical certification.

## Required Architecture Change

Human readiness output should show the profile caveat next to the profile id.

## Smallest Trial

Added `profile caveat:` to the human `packet-readiness` renderer.
