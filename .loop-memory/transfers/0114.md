# Tick 0114 Cross-Domain Transfer

Open question: Paper QA gap: threshold provenance and single-measure diagnostic-overclaim checks should be implemented.

Fields considered:

- Jury procedure / legal discovery: chain-of-custody and admissibility rules. Useful because every threshold-based claim should trace from evidence to paper text to citation.
- Aviation safety: checklist callouts for irreversible category changes. Useful because "threshold-defined measured status" can accidentally become "diagnosis" in prose.
- Cartography / map-making: legends separate symbol thresholds from territory. Useful because threshold categories are map legends, not clinical reality.

Chosen technique: legal chain-of-custody. A threshold is now treated as evidence that must be accompanied by explicit provenance and caveat language before it is admissible in a paper.

Structural mapping:

- Evidence threshold object -> source exhibit.
- Paper threshold definition -> chain-of-custody statement.
- Citation URL -> admissibility reference.
- Diagnostic caveat -> limiting instruction to the reader.

Required architecture change: extend `research paper-qa` with threshold-sensitive checks rather than creating a new paper-specific validator.

Smallest trial: added checks for `threshold-provenance`, `single-measure-kidney-caveat`, `single-measure-bp-caveat`, and `diagnosis-overclaiming`; re-ran against the UACR/hypertension paper.

Status: implemented and verified. The UACR paper now passes 21/21 paper QA checks under the stricter threshold rules.
