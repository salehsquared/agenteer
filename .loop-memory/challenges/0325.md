# Tick 0325 Challenge - Skeptical Statistician On Trust-Layer Method QA

Persona: Skeptical statistician.

## Critique

The trust layer is improving, but it still mixes route-specific and generic diagnostics too aggressively. The diagnostic accuracy golden packet now correctly recognizes sensitivity/specificity/PPV/NPV as estimate evidence, but it is still warned for missing collinearity and influence diagnostics. That is not a meaningful warning for a thresholded 2x2 diagnostic table. It makes the reviewer discount the whole warning stream because some warnings are plainly inapplicable.

The semantic-plausibility warning is also too broad. It fires because the diagnostic packet records sparse diagnostic cells, which is real, but the category message says “clinical coding concerns” even when no coding system exists in the packet. A sparse diagnostic cell is a precision/stability issue; coding review is a phenotype issue. Those should not share one vague warning.

The output is close to useful, but a method reviewer needs three things:

1. Route-specific applicability: only ask for diagnostics that belong to the method family.
2. Precise failure class: sparse diagnostic cell, clinical coding uncertainty, missingness, survey-design mismatch, and model instability are different problems.
3. Actionable readiness: if the only remaining issue is a sparse diagnostic cell already called out in the paper, `needs_methods_review` is right, but the next action should say “review sparse diagnostic cell stability,” not “regenerate manuscript.”

## Actionable Implications

- Add route-family normalization before QA checks.
- Skip or mark not-applicable regression-only diagnostics for `diagnostic_accuracy`, `descriptive`, and other non-regression routes.
- Split sparse-cell / precision-stability warnings from clinical coding / semantic-plausibility warnings.
- Make `nextRecommendedAction` include the dominant unresolved issue class.

## Evidence That Would Change This Critique

- `run-inspect` on `.loop-memory/golden/0229-diagnostic-threshold-route` has no collinearity/influence warnings.
- The remaining warning names the sparse diagnostic cell precisely.
- The next action points to sparse diagnostic cell review rather than generic methods review or manuscript regeneration.
- Tests prove diagnostic accuracy and regression routes receive different diagnostic requirements.
