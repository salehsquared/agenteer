# Tick 0107 Challenge

Persona: Methodology archivist

## Critique

The next phase must not call generated markdown "research papers" unless the artifact has a visible paper contract. For NHANES papers, the minimum contract is stricter than a normal report: title, structured abstract, methods, dataset/sample construction, variables, statistical approach, results, limitations, reproducibility, citations, and a critique/QA companion.

The web search reinforces this:

- STROBE describes a 22-item reporting checklist for observational studies. Applicability: every paper artifact should include enough methods/results/limitations detail for a STROBE-style QA pass. Source: https://www.strobe-statement.org/
- CDC NHANES analytic guidelines emphasize survey design, weighting, and variance estimation. Applicability: every paper must explicitly state whether survey weights/strata/PSU were used, approximated, or not fully implemented. Source: https://wwwn.cdc.gov/nchs/nhanes/AnalyticGuidelines.aspx
- The 2017 ACC/AHA hypertension guideline uses the 130/80 mm Hg threshold. Applicability: vitamin-D/BP papers using this threshold need a citation and should say it is a threshold definition, not a clinical diagnosis from one exam. Source: https://professional.heart.org/en/science-news/2017-hypertension-clinical-guidelines/top-things-to-know
- TARMOS argues missing data handling/reporting in observational studies needs explicit planning and reporting. Applicability: paper QA should flag missingness when exposure, endpoint, weight, or covariates lose many rows. Source: https://arxiv.org/abs/2004.14066

## Actionable Implications

- Generate paper artifacts only with companion evidence and QA JSON.
- QA should block or warn on missing limitations, missing survey-weight language, missing sample construction, missing citations, and causal overclaiming.
- The first actual paper should use the vitamin-D/BP packet because it already has merged cohort feasibility evidence.
- Subsequent papers should deliberately differ in domain and estimand, not only change labels.

## Evidence That Would Change This Critique

- A generated NHANES paper plus QA artifact where all required paper sections are present, survey limitations are explicit, missingness is quantified, citations are included, and causal language is bounded.
