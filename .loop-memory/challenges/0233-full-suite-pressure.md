# Challenge 0233 - Full Suite Pressure

## Critique

The diagnostic route now passes the broader `research-ml` suite, but this reveals a strategic problem: the research machine is getting healthier inside one dense test file while route families remain uneven.

What the suite proves:

- modeling-plan still works
- backend-status routing still works
- prior-run posture routing still works
- supervised ML, clustering, dimensionality reduction, and comparison still work
- stats-run and diagnostic accuracy still work
- analysis-run, manifest, benchmark, strict binding, survey refusal, and method binding still work

What it does not prove:

- actual NHANES diagnostic packet generation
- share/export safety for diagnostic papers
- rerun stability for diagnostic threshold packets
- paper-lifecycle integration for root-level diagnostic papers
- separate regression coverage for optional paper artifacts in non-diagnostic stats routes

## Required Response

The next implementation tick should add one of:

- diagnostic rerun stability over `paper.md`, `paper-qa.json`, `stats-run.json`, and `analysis-run-manifest.json`
- lifecycle/index visibility for diagnostic paper artifacts
- an actual NHANES-shaped diagnostic packet using cached/public data

## Counter-Design Rejected

Do not count full-suite green as the end of the diagnostic track. It proves no regressions, not scientific completeness.
