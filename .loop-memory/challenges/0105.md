# Tick 0105 Challenge

Persona: Skeptical statistician

## Critique

The vitamin-D/blood-pressure packet is `ready_for_local_real_data`, but that readiness is too permissive if interpreted as analytic feasibility. It proves files exist, summaries ran, variables were observed, and survey-method artifacts are present. It does not prove a usable analytic cohort exists after merging domains, adult eligibility, nonmissing vitamin D, nonmissing blood pressure measurements, and positive survey weights.

The data summaries show real feasibility pressure:

- `LBXVIDMS` missing fraction: about 11.9%.
- `BPXSY1` and `BPXDI1` missing fraction: about 46.2%.
- `WTMEC2YR` missing fraction in demographics: about 28.4%.
- oscillometric BP fields are about 79.6% missing and should not silently mix with auscultatory BP fields.

The current readiness name is acceptable only if it means "ready to attempt local real-data execution." It is not enough for "ready to trust a study design." The next pipeline primitive should estimate merged eligible rows and flag high-missingness variables before analysis generation.

## Actionable Implications

- Add a cohort-feasibility or semantic-missingness summary that consumes `data-access.json` and protocol/runner variables.
- Distinguish variable-present from variable-usable.
- Require a merged-domain cohort scout before report generation for actual-data packets.
- Make high missingness advisory or blocking based on whether the variable is exposure, endpoint, weight, or covariate.

## Evidence That Would Change This Critique

- A merged scout showing adult eligible row count, nonmissing exposure/endpoint/weight count, and sparse-cell checks.
- A semantic quality artifact that marks BP field family consistency and high-missingness variables by role.
- A report critique that blocks strong claims when actual analyzable N is unknown.
