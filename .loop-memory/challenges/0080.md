# Tick 0080 Challenge

Persona: Reliability engineer

## Critique

The new Parquet path works, but the reliability boundary is under-specified. `research table-summary` and `suggest-variable-map` can now depend on an external Python runtime selected by flag or environment variable. That is acceptable as an escape hatch, but it is not yet a reproducible research contract. A packet created on this machine can succeed because `/Users/saleh/WebstormProjects/medbrevia_v3/.venv-analytics-pilot/bin/python3` exists, while the same packet can fail elsewhere without a clear preflight artifact saying which runtime, package versions, and read-only data roots were used.

The failure mode is subtle: the command can produce valid-looking variable-map suggestions, but the evidence trail does not yet bind those suggestions to a specific table summary hash, Python runtime, pandas version, pyarrow version, file size, schema, or source data mtime. If later analysis changes, the user will not know whether the cause was a protocol change, a data file change, a Python environment change, or a summarizer implementation change.

The current bridge also risks becoming a hidden second runner. It starts as inspection, then variable mapping, then likely semantic quality and cohort scouting. Without a named boundary, Agenteer may slowly replicate MedBrevia's deterministic runner in TypeScript/Python fragments instead of defining a clean `real-data-adapter` contract.

## Actionable Implications

- Add a real-data environment preflight artifact before broadening Parquet use.
- Record Python executable, Python version, pandas version, pyarrow/fastparquet availability, file size, and file mtime in table-summary output.
- Make `suggest-variable-map` cite the table-summary evidence it used, or write a summary artifact before suggestions.
- Do not wire Parquet into `cohort-scout-file` until the adapter boundary is named.
- Prefer a manifest-driven `real-data-adapter` contract over ad hoc flags spreading across commands.

## Evidence That Would Change This Critique

- A packet can be moved to a clean environment and fail with a clear missing-runtime diagnostic before any partial inference.
- Table summaries include enough runtime and file provenance to compare two runs.
- Real-data commands share a single adapter contract instead of each inventing its own Python handoff.
- MedBrevia's deterministic scout can be represented as an external adapter without copying its domain-specific code into Agenteer.
