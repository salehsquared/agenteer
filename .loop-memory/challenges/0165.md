# Tick 0165 Challenge - Framework Minimalist

## Critique

The loop is adding useful contracts, but it risks burying the research workflow under too many parallel artifact systems: paper QA, runner records, task envelopes, capability declarations, evidence receipts, indexes, manifests, and tick memory. Each object is defensible alone. Together, they are becoming too much manual paperwork for one paper.

The spec-governed PIR/HDL paper is the right direction, but the system still asks the orchestrating agent to remember which wrappers to create. That means Agenteer has not yet internalized the golden path. A minimal framework would expose one research-paper run packet view that says: pre-run spec present, paper present, QA pass, runner binding, task validation, capability validation, share posture, and next blocker. Instead, the reviewer must inspect six files and mentally join them.

The interop layer is also too generic for the current maturity point. MCP/A2A exports are useful future-facing shapes, but for medical/public-health research the more urgent need is a local reviewer dashboard that prevents misinterpretation. The current direction can become "standards complete but user-hostile."

Finally, capability declarations stored in `.loop-memory` are useful dogfood artifacts, but they are not yet discoverable by commands. If every task validation requires manually passing three `--capability` flags, the framework has created another hidden ritual.

## Actionable Implications

1. Add a compact paper lifecycle summary that joins paper QA, runner record, task validation, capability validation, and binding posture.
2. Prefer one reviewer-facing command or artifact over more separate wrappers.
3. Make capability discovery automatic from a directory or registry before expanding interop exports.
4. Use task envelopes only when they reduce reviewer burden, not just because the standard exists.
5. Keep MCP/A2A export as secondary evidence until local correctness is smoother.

## Evidence That Would Change This Critique

- A single paper lifecycle artifact that makes the current state obvious in under ten lines.
- Automatic capability registry loading for task validation.
- A paper index that distinguishes retrospective, spec-governed, task-validated, and share-safe states without opening each directory.
- A new paper generated with fewer manual commands than the retrospective BMI/HbA1c paper.
