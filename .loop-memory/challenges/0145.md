# Tick 0145 Challenge: Skeptical Statistician

## Critique

The golden packet is now reproducible in the engineering sense, but it is still only approximately survey-aware. The current evidence proves that the same approximate weighted model reruns stably; it does not prove that variance estimates, confidence intervals, p values, or population-level claims are correct for pooled NHANES complex survey data.

The biggest risk is that reproducibility language could crowd out methods language. A stable rerun of the wrong estimator is still wrong. The packet correctly includes approximate-variance caveats, but the manifest treats rerun stability, paper QA, and runner provenance as peer readiness gates while the methods caveat remains a textual limitation rather than an enforceable policy.

The repair loop also risks over-repairing executable failures while under-classifying methodological failures. For example, `RERUN_DIFF_UNSTABLE` is executable and repairable. But "uses approximate variance where Taylor-linearized or replicate-weight variance is required" is not repairable by patching a report; it needs either a stronger runner or an explicit downgrade of inferential language.

## Actionable Implications

1. Add an explicit AnalysisSpec failure or inference policy that separates executable blockers from methodological blockers.
2. Make the golden packet declare whether estimates are descriptive, associational with approximate variance, or design-corrected inferential estimates.
3. Ensure report QA or manifest verification blocks strong p-value language when the spec says variance is approximate.
4. Add a future runner task: either implement design-correct survey variance or force all current CIs/p values into "approximate exploratory" language.

## Evidence That Would Change This Critique

- A runner record showing execution with a complex-survey design estimator and the exact NHANES pooling/weight construction rules used.
- An AnalysisSpec field that governs allowed inference strength and is checked by QA.
- A test where a paper with approximate-variance spec but overstrong inferential language fails.
