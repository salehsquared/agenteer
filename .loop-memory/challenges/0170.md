# Tick 170 Challenge - Reliability Engineer

## Critique

`research paper-run` is now impressive enough to be dangerous. It can produce polished, fully packaged papers from real NHANES cache data, but reliability is only proven for the paths recently exercised: MEC-weighted linear regression, MEC-weighted logistic regression, and a narrow set of packet artifacts. The next likely failure is not a crash; it is silent methodological misuse.

The biggest reliability risk is weight-domain ambiguity. A fasting-glucose or lab-subsample study can technically run today if the AnalysisSpec names `WTSAF2YR`, but the runner does not yet make subsample eligibility, least-common-denominator weight choice, or domain restrictions first-class evidence. That means a paper could pass lifecycle checks while hiding that its denominator and inference population changed.

The second risk is a single-command success path with insufficient preflight refusals. `paper-run` should not just execute whatever variable set is present; it should detect whether the chosen weight is compatible with the outcome/exposure domains, whether a subsample flag must be disclosed, and whether the paper language identifies the weighted analytic population.

The third risk is reproducibility confidence drift. We now generate many artifacts automatically, but the system still lacks a packet-level rerun-stability check for fresh `paper-run` outputs. A packet can be ready for local review without proving that a second run from the same AnalysisSpec produces equivalent model evidence.

## Actionable Implications

- Add explicit subsample-weight evidence before generating a fasting-glucose paper.
- Require paper prose and evidence JSON to disclose subsample weights when `WTSAF2YR`, `WTSAFPRP`, or similar subsample weights are used.
- Add a typed warning or blocker when an AnalysisSpec uses a subsample weight but no subsample rationale or eligibility note.
- Prefer a rerun-stability artifact for at least one fresh `paper-run` packet before claiming golden-path maturity.

## Evidence That Would Change This Critique

- A real fasting/subsample NHANES paper packet whose evidence records the subsample weight, rationale, eligible population, complete-case denominator, and paper caveats.
- A deterministic test proving subsample-weight AnalysisSpecs cannot silently produce ordinary-MEC language.
- A rerun-diff or manifest-level repeat check for generated `paper-run` packets.
