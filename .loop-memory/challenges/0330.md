# Tick 0330 Challenge - Pulmonary Packet Reliability Review

Persona: Reliability engineer.

## Critique

The pulmonary/COPD packet is real and useful, but its apparent QA pass can hide an operational reliability problem: the mortality model uses only 4,680 complete-case rows out of 25,835 cohort rows because several first-day respiratory/lab variables are highly missing. That is not automatically wrong, but a packet that reports large-cohort cohort counts beside much smaller model counts must make the analytic denominator shift prominent.

The packet also combines COPD and acute respiratory failure code families. This is clinically reasonable as a broad respiratory-failure stress case, but it is not a single clean phenotype. COPD, acute respiratory failure, chronic respiratory failure, and mixed acute-on-chronic respiratory failure may have different etiologies, baseline physiology, treatment pathways, and mortality risks.

The existing QA says pass because model fitting and cache cleanup succeeded. A reliability-grade research packet should additionally prove:

- phenotype breadth is intentional and not a substring accident;
- broad-vs-narrow phenotype sensitivity is planned;
- model complete-case denominator is visible in the first screen;
- high-missingness variables are not interpreted as general cohort findings;
- respiratory markers are separated from care-process markers when possible;
- the report does not use "predict" in a deployable clinical sense without validation.

## Actionable Implications

- Validation tick 0331 should run trust-layer checks and verify whether high missingness downgrades the packet to methods review.
- The issue ledger should distinguish original runner `pass` from trust-layer readiness.
- Future MIMIC runner promotion should add phenotype-sensitivity contracts and high-missingness complete-case denominator warnings during execution.

## Evidence That Would Change This Critique

This critique would soften if the packet had a predeclared phenotype policy, sensitivity analyses for COPD-only versus respiratory-failure-only cohorts, explicit denominator shifts in the abstract/results, and diagnostics proving missingness does not drive the apparent associations.
