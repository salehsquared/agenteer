# Challenge 0371: Source Appraisal Gap

Source count, PubMed presence, and source type are not enough to decide whether a study is well supported. The connector can identify useful planning signals, but true appraisal needs study-design-specific rubrics: diagnostic accuracy bias, prediction-model validation, causal observational confounding, survey methods, guideline certainty, and systematic-review quality.

Decision: use current literature context for planning and claim boundaries, not as a final certainty grade.
