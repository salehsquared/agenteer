# Challenge 0197 - End-User Clinician - packet artifacts are improving faster than interpretability

## Persona

End-user clinician.

## Critique

The platform is getting better at generating artifacts, but the reviewer experience still asks too much of the human. `stats-run` now produces a report and QA, but a clinician or applied researcher still has to infer:

- whether this was the right analysis for the question
- whether standard-table inference was appropriate for the dataset
- whether the result is descriptive, associational, predictive, or causal
- whether the reported effect is clinically meaningful or only numerically nonzero
- whether the packet is ready to read, ready to rerun, or only an exploratory run

The bigger risk is not missing method breadth. The bigger risk is generating a growing pile of technically correct artifacts that still require an expert to reconstruct the decision story.

## Actionable Implications

- The next implementation should generate one compact run-level interpretation boundary for stats and ML runs, not only per-artifact reports.
- Lifecycle should expose runner family, inferential posture, binding posture, and "what this result can and cannot support."
- For stats-run, a successful unbound run should be visibly `exploratory_standard_table`, not simply "succeeded".
- For ML-run, model metrics should not imply clinical usefulness without calibration, leakage checks, and threshold/decision policy.
- Avoid expanding advanced methods until the basic result posture is unambiguous.

## Evidence That Would Change This Critique

- A user can run `modeling-plan -> stats-run` or `modeling-plan -> ml-run` and see a single lifecycle/readiness view that states result posture and next action.
- The output names the analysis as descriptive/associational/predictive/causal-stop instead of leaving the category implicit.
- A successful run with weak binding or missing design evidence is clearly labeled exploratory.

## Priority

High. This affects whether artifacts are usable by humans, not just whether they exist.
