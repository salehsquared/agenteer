# Tick 0393: survival and longitudinal validation

Axis: remove-or-merge
Contribution: methods + runner + QA

## Hypothesis

Survival and longitudinal routes should either execute cleanly with appropriate artifacts or fail with explicit backend blockers. Validation should remove ambiguity between unsupported methods and broken implementations.

## Scope

Validate survival and longitudinal routes and repair any runner defect exposed by the suite.

## Intervention

Ran survival/longitudinal routes under `.loop-memory/stats-method-validation-20260509/runs/0393-*`:

- `kaplan-meier`
- `log-rank`
- `cox-proportional-hazards`
- `stratified-cox`
- `aalen-johansen-cif`
- `recurrent-event-rate`
- `linear-mixed-model`
- `gee`
- `repeated-measures-anova`
- negative-control blockers: `fine-gray`, `time-varying-cox`, `generalized-mixed-model`

The first `recurrent-event-rate` run exposed a real bug: `--id` was validated but not retained in the complete-case frame. The same pattern could affect `--strata` for stratified Cox. Fixed the stats runner to include `id` and `strata` fields in the survival complete-case variables and added regression coverage.

## Evidence

- 9/9 executable survival/longitudinal routes succeeded.
- `kaplan-meier` and `aalen-johansen-cif` produced curve figures.
- `fine-gray` and `time-varying-cox` failed with `METHOD_BACKEND_NOT_AVAILABLE`.
- `generalized-mixed-model` failed with `GLMM_BACKEND_NOT_AVAILABLE`.
- Regression test updated: `packages/cli/tests/research-stats-methods.test.ts`.
- Runner fix: `packages/cli/src/research-machine/stats/runner.ts`.

## Verification

Ran all survival/longitudinal CLI routes, rebuilt after the fix, reran `recurrent-event-rate`, and summarized `stats-run.json`, `stats-qa.json`, and `figures.json`.

## Decision

Promote executable survival/longitudinal standard routes to validated. Keep Fine-Gray, time-varying Cox, and GLMM registered-but-blocked until a validated backend is available.

## Counter-Design Considered

Rejected treating the recurrent-event crash as just a validation-suite artifact. The bug was in the shared runner variable contract and needed a production fix plus test coverage.

## Memory Updates

Recorded the survival/longitudinal validation result and backend blocker boundary.
