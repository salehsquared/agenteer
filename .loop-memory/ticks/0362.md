# Tick 362: literature readiness gate

Axis: more-robust
Contribution: QA + safety

## Hypothesis
Literature QA should affect promotion readiness when it is attached to a medical/public-health packet.

## Deliverable
`research run-inspect` now blocks readiness for failed literature retrieval/QA and downgrades readiness to methods review when literature warnings exist.

## Verification
Added regression coverage in `packages/cli/tests/research-trust.test.ts` proving warning-level literature QA downgrades inspection readiness and surfaces source/citation counts.

## Counter-Design Considered
Rejected treating literature evidence as advisory-only once it is attached to a packet; attached evidence must participate in readiness.

## Next Tick
Avoid forcing users to run manual context steps before `analysis-run`.
