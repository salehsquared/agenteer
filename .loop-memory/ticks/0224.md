# Tick 0224 - Web Search / Diagnostic Route Semantics

## Hypothesis

Diagnostic accuracy should be represented in the planning/front-door layer as diagnostic methodology, not as generic association.

## Scope

Small code hardening, docs, refreshed golden route artifacts, and source-backed interpretation notes.

## Intervention

- Reviewed STARD diagnostic accuracy reporting guidance and the 2025 STARD-AI extension as external pressure.
- Updated `modeling-plan` command hints for `diagnostic-accuracy` to name a binary reference standard and binary index test.
- Updated `analysis-run` so `--method diagnostic-accuracy` records `goal=diagnose`, `outcomeType=binary`, and `studyDesign=diagnostic` in both pre-run and post-run modeling plans.
- Extended the diagnostic accuracy test to verify modeling-plan and analysis-run route semantics.
- Refreshed `.loop-memory/golden/0223-diagnostic-accuracy-route` artifacts.
- Updated `docs/research-ml.md` with STARD/STARD-AI diagnostic caveats.

## Evidence

- `npm run build` passed.
- `npm test -- packages/cli/tests/research-ml.test.ts -t "diagnostic accuracy"` passed.
- Refreshed diagnostic route now reports `goal=diagnose`, `studyDesign=diagnostic`, route `stats-run`, and command hint `--method diagnostic-accuracy --outcome <binary-reference-standard> --exposure <binary-index-test>`.
- Strict three-route benchmark still passes with 3/3 local-review-ready manifests and `multi_route_ready` coverage.

## Verification

Build, targeted diagnostic test, refreshed CLI route, and strict benchmark all passed.

## Decision

Use STARD-like role naming as the default diagnostic front-door language. Keep STARD-AI as a future pressure source for AI diagnostic workflows, not a claim about the current classical route.

## Counter-Design Considered

Rejected leaving diagnostic route semantics inside `stats-run` only. Execution correctness is not enough if the planning artifact tells future agents the wrong study shape.

## Memory Updates

Updated `MEMORY.md`, `improvements.md`, `open-questions.md`, and `rejected.md`.

## Next Tick

Tick 0225 is a more-robust axis. It should add diagnostic accuracy report QA checks for reference-standard/index-test language, predictive-value caveat, and screening-recommendation overclaim.
