# Tick 184 - add primitive - executable classical statistics runner

## Axis

Add primitive / methods / runner.

## Hypothesis

If Agenteer can execute common classical statistics methods directly, the research pipeline can cover standard papers without forcing every non-survey analysis through ML or bespoke Python.

## Deliverable

Added `research stats-run`, a bounded Python-backed runner for standard table methods:

- descriptive summaries
- Welch two-sample t-test
- Mann-Whitney U
- chi-square independence
- Fisher exact test
- Pearson and Spearman correlation
- linear regression
- logistic regression
- Poisson regression with overdispersion warning

The runner writes `stats-run.json`, `stats-summary.json`, `estimates.csv`, and `diagnostics.json`, and returns SHA-256 hashes for artifacts. It is explicitly documented as standard table statistics, not a replacement for complex-survey `paper-run --backend r-survey`.

Saved CLI smoke evidence under `.loop-memory/modeling/0184-stats-smoke/`.
