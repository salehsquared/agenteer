# Tick 358: literature context as planning evidence

Axis: add-primitive
Contribution: architecture + methods

## Hypothesis
MedBrevia search output should become a reusable research-planning artifact rather than a one-off search transcript.

## Deliverable
Added `research literature-context`, a normalized artifact that turns MedBrevia literature search packets into evidence strength, design signals, method signals, planning implications, follow-up searches, and issue records.

## Verification
`npm run build --workspace @agenteer/cli` passed.
`npx vitest run packages/cli/tests/research-literature.test.ts` passed.

## Counter-Design Considered
Rejected feeding raw search JSON directly into every downstream command because that would couple planning, QA, and inspection to MedBrevia response details.

## Next Tick
Critique whether the connector is visible enough in the rest of the research lifecycle.
