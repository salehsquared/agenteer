## Findings

- RO-Crate training material says folder-based crates refer to content with relative paths, and absolute paths are avoided so the crate can move or be archived. Applicability: Agenteer exports should not preserve `/Users/...` paths by default. Source: https://training.galaxyproject.org/training-material/topics/fair/tutorials/ro-crate-intro/tutorial.html
- DataCite's monthly data file uses manifest records containing filename, size, and SHA-256 checksum. Applicability: exported Agenteer data-access evidence can preserve basename/sourceRef, size, and hash without local absolute paths. Source: https://support.datacite.org/docs/datacite-monthly-data-file
- Reproducibility training from Yale/Frontier Science explicitly includes converting absolute file paths to relative file paths and identifying packages required to execute code. Applicability: Agenteer should keep runtime/package provenance, but use relative or redacted paths at export/share boundaries. Source: https://isps.yale.edu/sites/default/files/files/YSPH-reproducibility_April2018-Peer%281%29.pdf

## Design Consequence

The export/share policy should be:

- Internal artifacts may keep absolute `localPath`.
- Exported/share posture should use `sourceRef`, basename, size, SHA-256, and adapter/runtime package metadata.
- Packet readiness should warn when local absolute paths appear in shareable artifacts.
- `research export` should either redact absolute paths or include a clear local-only warning artifact.
