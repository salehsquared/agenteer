# Tick 360: literature role boundary

Axis: question-the-question
Contribution: methods

## Hypothesis
Not every local exploratory analysis should require a literature search, but every promoted medical/public-health packet should expose whether literature evidence exists and what it supports.

## Deliverable
Defined the role boundary: literature context influences planning and claim boundaries; it does not replace dataset evidence, AnalysisSpec validation, or methods QA.

## Verification
The boundary was encoded into docs and command behavior: `modeling-plan --literature` adds warnings and routing signals, while `analysis-run --literature` persists evidence for later QA.

## Counter-Design Considered
Rejected making MedBrevia search mandatory for all runs because local fixture tests, engineering benchmarks, and non-medical datasets should remain cheap and deterministic.

## Next Tick
Integrate literature evidence into unified run inspection.
