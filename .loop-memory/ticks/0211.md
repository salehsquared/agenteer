# Tick 0211 - Faster/Simpler / ML Review Card

## Hypothesis

The fastest way to make ML comparison less metric-centric is to emit model-card-style review evidence by default from `ml-compare`, not to add another command.

## Scope

- Add review-card JSON fields to ML comparison output.
- Write `model-review-card.md` beside `comparison.json`.
- Keep this deterministic and local.

## Intervention

`ml-compare` now writes `model-review-card.md` and includes `reviewCard` in JSON:

- intended use
- intended non-use
- validation boundary
- subgroup evidence status
- leakage review
- missing evidence
- ranked models

## Evidence

Verification passed:

- CLI smoke: `ml-compare --json` returned `reviewCard.status=local_review_ready` and the referenced Markdown file existed.

## Decision

Make review cards default comparison output. Prediction review evidence should be generated with the comparison, not remembered afterward.

## Counter-Design Considered

Rejected creating a separate `ml-review-card` command. The faster, safer path is for every `ml-compare` run to emit review-card evidence by default.
