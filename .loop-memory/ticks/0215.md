# Tick 0215 - Challenge / Benchmark Truth Pressure

## Hypothesis

The current analysis benchmark gate can create false confidence because it checks readiness one run directory at a time but does not yet prove a bound stats route and an ML comparison route pass together as one benchmark suite.

## Scope

Challenge tick only. No code changes.

## Intervention

Reviewed the newest analysis benchmark layer against the outcome contract and current golden route evidence. The intervention is a written challenge, not a code change.

## Critique

`analysis-benchmark` is a useful consolidation step, but it is still too thin to carry promotion pressure by itself. It currently answers "did each manifest pass?" but not "does this suite cover the failure modes the outcome contract cares about?"

Main risks:

- The active stats golden route is still unbound and therefore exploratory. A benchmark that only passes ML comparison readiness can hide the weaker stats route.
- The benchmark result lacks an explicit coverage summary across route kinds. A single passing ML comparison can look like broad maturity even when stats and paper routes were not exercised.
- The benchmark does not preserve a durable report artifact unless the caller captures stdout/JSON manually.
- The benchmark does not yet encode recent agentic-evaluation lessons: diverse tasks, explicit reward/gate definitions, failure-mode accounting, and reproducibility metadata.
- The ML route has a review card, but stats routes only have `stats-report.md` and `stats-qa.json`; the suite does not yet compare whether both paths expose equivalent interpretation boundaries.

## Decision

Do not promote the benchmark layer as mature until the next ticks create a bound stats golden route, run a two-route benchmark, and add coverage/reporting pressure.

## Counter-Design Considered

Rejected treating `.loop-memory/golden/0212-ml-comparison-route` as enough benchmark evidence. Prediction readiness and standard-table inference readiness fail in different ways and both must be present.
