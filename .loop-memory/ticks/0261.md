# Tick 0261 - Capability Rave - Route Intent

## Scope

Label: `UX`, `methods`, `architecture`.

Use the capability-rave protocol to find the smallest high-leverage exploration improvement. Selected item: route intent plus a concise recommended question.

## Hypothesis

If exploration emits route intent and a single recommended next question, the report becomes easier to operate and downstream planning no longer has to infer study intent only from text.

## Intervention

- Wrote `.loop-memory/malleability/0261.md`.
- Added candidate `routeIntent` and `routeIntentRationale`.
- Added run-level `recommendedQuestion` with question id, question text, route intent, primary use, reason, and next command.
- Added `route-intent` QA.
- Added a `Recommended Next Question` section near the top of the report.
- `explore-promote` now carries route intent through `modelingPlanSeed`.
- `modeling-plan --exploration-handoff` defaults `goal=associate` for explanatory-association route intent.
- Updated docs and tests.

## Evidence

Actual NHANES exploration now recommends:

- question: `Is RIDAGEYR associated with LBXGH in this dataset?`
- route intent: `explanatory_association`
- primary use: `recommended`
- next command: `research explore-promote ...`

The handoff carries `routeIntent=explanatory_association`; `modeling-plan` infers `goal=associate` and routes to `paper-run` under `--survey`.
