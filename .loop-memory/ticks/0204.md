# Tick 0204 - First Principles / Bounded Route

## Hypothesis

The smallest useful automation is not a general autonomous analyst; it is a bounded route command that preserves every intermediate artifact while removing manual sequencing errors.

## Scope

- Add a bounded standard-table stats route.
- Preserve `modeling-plan`, `stats-run`, `analysis-manifest`, and post-run prior evidence artifacts.
- Do not add arbitrary model-family selection or hide human-in-the-loop artifacts.

## Intervention

Added `research analysis-run --question <text> --method <stats-method> --data <rows> --out-dir <dir> ...`.

It writes:

- `modeling-plan.json`
- `stats-run/` with all stats artifacts
- `stats-run-envelope.json`
- `stats-run/analysis-run-manifest.json`
- `modeling-plan-after-prior.json`

The returned object includes the stats result, analysis manifest, post-run modeling plan, generated file paths, and next action.

## Decision

Keep `analysis-run` bounded to standard-table stats for now. It reduces sequencing friction while preserving all human-review artifacts.

## Counter-Design Considered

Rejected a fully autonomous all-method runner. First principles favor one bounded, inspectable stats route before allowing the command to pick arbitrary modeling families.
