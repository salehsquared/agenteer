# Tick 0381: propensity matching becomes standard

Axis: remove-or-merge
Contribution: methods + runner

## Hypothesis
The paper series should not rely only on adjusted regression; each exposure study should also emit propensity matching diagnostics when a binary exposure and covariates permit it.

## Scope
Add propensity matching to the runner and run the sepsis/RRT paper.

## Intervention
Implemented 1:1 greedy nearest-neighbor propensity matching with logistic propensity scores, caliper support, no replacement, before/after standardized mean differences, matched-pair files, propensity-score files, matched risk difference, discordant-pair odds ratio, LOS difference, unmatched treated accounting, and typed QA issues.

## Evidence
- Paper: `.loop-memory/mimic-dialysis-cardiac-papers-20260509/papers/0381-dialysis-sepsis-rrt/paper.md`.
- Cohort rows: 13,730.
- Propensity matching: fit.
- Typed issue: `PROPENSITY_RESIDUAL_IMBALANCE`.
- Artifacts include `propensity-balance.csv`, `matched-pairs.csv`, and `propensity-scores.csv`.

## Verification
Ran the runner and `research run-inspect`; paper QA passed and inspection blockers were zero.

## Decision
Use propensity matching as a methods-review artifact across the rest of the paper series. Treat imbalance/unmatched warnings as review gates, not failures to hide.

## Counter-Design Considered
Rejected only reporting the adjusted odds ratio. Regression-only output is too easy to overread and gives no transparent overlap/balance evidence.

## Memory Updates
Recorded propensity artifacts as mandatory for this paper batch when the exposure is binary and covariates exist.

Run heart-failure RRT with the new propensity path and verify the same artifact contract.
