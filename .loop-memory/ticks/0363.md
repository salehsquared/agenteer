# Tick 363: merge raw search and context entrypoints

Axis: remove-or-merge
Contribution: UX

## Hypothesis
Users should not have to know whether they have a raw MedBrevia search packet or a derived literature context packet.

## Deliverable
`research modeling-plan --literature` accepts either raw search JSON or context JSON. Raw search packets are converted to context internally.

## Verification
The manual CLI smoke passed using `literature-context` followed by `modeling-plan --literature`; targeted tests also cover the context route.

## Counter-Design Considered
Rejected separate `--literature-search` and `--literature-context` flags because the pipeline should be forgiving at the boundary.

## Next Tick
Use web-grounded reporting guidance to shape the connector’s evaluation pressure.
