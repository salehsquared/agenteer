# Tick 372: optional versus promotion-gating literature

Axis: question-the-question
Contribution: policy

## Hypothesis
Literature should remain optional for cheap local runs but become readiness-relevant once attached or when a packet is being promoted as medical/public-health evidence.

## Deliverable
Recorded the policy boundary: absence of literature does not block all runs; failed/warning literature blocks or downgrades attached runs; future promotion profiles can require literature for selected study classes.

## Verification
`run-inspect` behavior matches this policy: missing literature is reported as missing but not automatically blocked, while warning/fail literature changes readiness.

## Counter-Design Considered
Rejected global mandatory literature because nonmedical tests, framework benchmarks, and early data exploration should remain fast.
