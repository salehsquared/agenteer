# Tick 0324 - Diagnostic Performance Evidence In Method QA

Axis: capability-rave.
Contribution: `methods, QA`.

## Hypothesis

If method QA recognizes diagnostic accuracy metrics as estimate evidence, then diagnostic packets with sensitivity, specificity, predictive values, likelihood ratios, and intervals will not be falsely downgraded for missing effect-size evidence.

## Scope

Harden the existing `effect_size` QA check. No new commands, no domain repo writes, and no new broad diagnostic framework.

## Intervention

Wrote `.loop-memory/malleability/0324.md` and selected the diagnostic-estimate recognition item. Updated `collectEstimateLikeRecords` to include diagnostic performance records when they contain diagnostic metrics plus diagnostic counts or intervals.

## Evidence

## Decision

Promotion decision: `promote`. This reduces false method-QA friction for diagnostic accuracy runs while keeping sparse-cell semantic warnings visible.

## Counter-Design Considered

Rejected treating diagnostic accuracy as exempt from effect-size QA. Diagnostic studies have effect/performance quantities; the correct fix is recognizing them, not skipping the gate.
