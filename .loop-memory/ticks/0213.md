# Tick 0213 - Remove/Merge / ML Comparison Manifest

## Hypothesis

ML comparison readiness should be inspected by the existing `analysis-manifest` primitive, not a separate comparison-manifest command.

## Scope

- Extend `analysis-manifest` to accept `comparison.json` roots.
- Require `model-review-card.md` for ML comparison local readiness.
- Keep one manifest surface for stats, ML runs, and ML comparisons.

## Intervention

`analysis-manifest` now detects `comparison.json` and emits `runKind=ml-comparison`. `local_review_ready` requires:

- `comparison.json`
- `model-review-card.md`
- `comparisonPosture.status=baseline_comparison_ready`
