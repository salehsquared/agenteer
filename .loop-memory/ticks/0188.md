# Tick 188 - more robust - bind stats runs to planning evidence

## Axis

More robust / methods / reproducibility.

## Hypothesis

If `stats-run` can bind to method-selection and AnalysisSpec evidence, it can stop manual command drift before execution.

## Deliverable

Added upstream binding support to `research stats-run`:

- `--method-selection <selection.json>`
- `--analysis-spec <spec.json>`
- persisted `binding` metadata in `stats-run.json`
- validation that the selected primary method maps to the requested stats method
- pre-execution failure on method-selection mismatch
- spec hash capture from AnalysisSpec V2 or stable hash fallback
- docs and tests

Saved CLI smoke evidence at `.loop-memory/modeling/0188-stats-binding/`.
