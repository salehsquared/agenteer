# Tick 171 - cross-domain - subsample weight clearance

## Axis

Cross-domain transfer / methods reliability.

## Deliverable

Imported an ATC-clearance/refinement-contract pattern into `research paper-run`: subsample NHANES weights now require an explicit pre-run AnalysisSpec rationale and eligibility note, and generated evidence/papers carry the weight-domain clearance boundary.

Implementation:

- `paper-run` generated runner recognizes common NHANES weight domains, including `WTSAF2YR` and `WTSAFPRP`.
- Subsample weights now refuse execution unless `surveyDesign.weightRationale` and `surveyDesign.eligibilityNote` are present.
- `analysis.json` now records `weights.domain` with `id`, `label`, `isSubsample`, `rationale`, and `eligibilityNote`.
- Generated papers disclose the weight-domain clearance in abstract/methods/limitations.
- `paper-qa` now has `subsample-weight-disclosure` and `subsample-weight-evidence` checks.
