# Tick 0394: causal and quasi-experimental validation

Axis: add-primitive
Contribution: methods + QA + reader artifacts

## Hypothesis

Causal and quasi-experimental routes should behave as design-review artifacts: they should run where mathematically supported, produce balance/assumption evidence, and avoid implying causal proof.

## Scope

Validate causal/quasi-experimental methods and prove that propensity routes can generate reader-facing papers with causal boundaries.

## Intervention

Ran 12 causal/quasi-experimental routes:

- `propensity-score-matching` via `analysis-run`, with `paper.md` and `paper-qa.json`
- `propensity-score-weighting` via `analysis-run`, with `paper.md` and `paper-qa.json`
- `overlap-weighting`
- `entropy-balancing`
- `doubly-robust-aipw`
- `difference-in-differences`
- `event-study-did`
- `interrupted-time-series`
- `regression-discontinuity`
- `instrumental-variables-2sls`
- `target-trial-emulation-spec`
- `unmeasured-confounding-sensitivity`

## Evidence

- 12/12 routes returned `status=succeeded`.
- Propensity matching and weighting generated reader-facing `paper.md` plus passing `paper-qa.json`.
- PSM correctly surfaced design-review issues: `PROPENSITY_UNMATCHED_TREATED` and `PROPENSITY_RESIDUAL_IMBALANCE`.
- Target-trial route correctly surfaced `TARGET_TRIAL_REVIEW_REQUIRED`.
- Propensity manifests have artifact completeness `pass` while readiness remains exploratory/design-review rather than causal proof.

## Verification

Ran all causal/quasi CLI routes from the built CLI and summarized run status, QA status, paper presence, and typed issues.

## Decision

Promote these routes as validated design-review primitives, not publication-ready causal inference engines. The reader-facing propensity papers are useful demos precisely because they carry causal boundaries and balance/positivity artifacts.

## Counter-Design Considered

Rejected treating successful propensity matching as a green causal estimate. Balance, overlap, unmatched treated rows, and target-trial assumptions remain part of the output and must constrain interpretation.

## Memory Updates

Recorded causal route validation and the distinction between executable design review and causal proof.
