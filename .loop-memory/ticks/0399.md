# Tick 0399: figure QA becomes a runner primitive

Axis: cross-domain
Contribution: QA + architecture + reproducibility

## Hypothesis

Generated papers will not be trustworthy demos until their figures are inspected as first-class artifacts, not just written as PNG side effects.

## Scope

Add a deterministic figure QA primitive and run the first figure-backed study packet.

## Intervention

- Added `research figure-qa --figures <figures.json>` with PNG decoding, dimension checks, file-size checks, nonblank-pixel checks, color-detail checks, caption checks, alt-text checks, axis-label checks, and source-column checks.
- Made `stats-run` automatically write `figure-qa.json` and add `figure-qa` to run artifacts.
- Added axis metadata/alt text to generated figures.
- Ran study 1, descriptive profile, with histogram and missingness figures.

## Evidence

- Figure suite index: `.loop-memory/figure-study-suite-20260509/STUDY_INDEX.md`.
- Study packet: `.loop-memory/figure-study-suite-20260509/studies/01-descriptive-profile/`.
- Figure QA status: pass.

## Verification

- `npm run build` passed.
- `npm test -- packages/cli/tests/research-stats-methods.test.ts` passed after adding figure QA coverage.

## Counter-Design Considered

Rejected visual-only review. Human inspection is useful, but the pipeline needs deterministic gates before a figure reaches a manuscript packet.

## Next Tick

Run a group-comparison paper and verify that simple comparison graphics remain readable under the stricter figure contract.
