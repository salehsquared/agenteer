# Tick 0207 - Capability-Rave / Readiness Gate

## Hypothesis

Artifact-complete manifests should not count as benchmark or promotion success unless they are also locally review-ready.

## Scope

- Add a hard readiness gate to the existing analysis manifest surface.
- Avoid creating a separate benchmark command.

## Intervention

`research analysis-manifest` now accepts `--require-ready`. In library usage, `researchAnalysisManifestCommand({ requireReady: true })` throws unless readiness is `local_review_ready`.

## Evidence

Verification passed:

- `PATH=/Users/saleh/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin:$PATH node_modules/.bin/tsc --build`

- CLI smoke: a bound strict `analysis-run` followed by `analysis-manifest --require-ready` returned `local_review_ready`.

## Decision

Keep artifact completeness and review readiness separate. Benchmark/promotion scripts can now demand the latter.

## Counter-Design Considered

Rejected treating exploratory manifest completion as enough for benchmark success. Artifact completeness and local-review readiness are separate gates.
