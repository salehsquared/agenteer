# Tick 0206 - More Robust / Methods Safety

## Hypothesis

`analysis-run` can remain convenient without normalizing unbound exploratory stats if it supports upstream evidence binding and a strict mode.

## Scope

- Add `--method-selection`, `--analysis-spec`, and `--require-bound` to `analysis-run`.
- Pass binding evidence into `stats-run`.
- Fail strict unbound runs before execution.
- Test bound and strict failure paths.

## Intervention

`analysis-run` now forwards method-selection and AnalysisSpec paths to `stats-run`. `--require-bound` throws before execution unless one of those evidence paths is supplied.

## Decision

Keep exploratory `analysis-run` available for local development, but strict mode is now a real enforcement gate for benchmark/paper-like runs.

## Counter-Design Considered
