# Tick 0331 - Pulmonary Packet Validation And Denominator QA

Axis: faster-or-simpler.
Contribution: `methods, QA, UX`.

## Hypothesis

If the trust layer directly reads model-specific denominators and model family evidence from MIMIC packets, then reviewers can see high-missingness denominator shifts without manually opening `analysis-results.json`.

## Scope

Validate the existing pulmonary/COPD packet and respond to the tick 0330 challenge. No new raw data reads and no domain repo edits.

## Intervention

Ran `method-qa`, `run-inspect`, and `manuscript` for the pulmonary packet.

Initial validation confirmed the challenge: the trust layer reported complete-case N as 25,835 even though the mortality model used 4,680 rows and the LOS model used 4,679 rows. I fixed `packages/cli/src/research-machine/trust.ts` so:

- method summaries prefer `models.*.n`, `models.*.events`, and model predictor arrays;
- missingness QA downgrades model denominator shrinkage relative to cohort size;
- model-family detection infers logistic routes from odds-ratio/risk-ratio/hazard-ratio estimates.

Added regression coverage in `packages/cli/tests/research-trust.test.ts`.

## Evidence

Final pulmonary validation:

- Method QA status: `warning`.
- Readiness: `needs_methods_review`.
- Detected model family: `logistic`.
- Complete-case N: 4,679.
- Events: 1,116.
- Predictors: 7.
- Main missingness warning: model complete-case denominator is 18.1% of the cohort (4,679 of 25,835).
- Additional warnings: explicit separation diagnostic missing, collinearity diagnostic missing, influence diagnostic missing.
- Manuscript QA: pass, title `# COPD And Respiratory Failure ICU Outcomes`, no internal-jargon hits.
