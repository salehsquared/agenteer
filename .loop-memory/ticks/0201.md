# Tick 0201 - Remove/Merge / Planning Gate

## Hypothesis

If prior stats/ML run posture is consumed by `modeling-plan`, the system can respond to failures and local-only results through the existing front door instead of adding another review command.

## Scope

- Add `--prior-run` support to `research modeling-plan`.
- Normalize `stats-run.json` and `ml-run.json` posture into a shared prior-run evidence object.
- Make route recommendation respond to prior posture.
- Do not add estimator breadth or a new lifecycle command.

## Intervention

`modeling-plan` now accepts one or more prior stats/ML run artifacts. It derives actions:

- `rerun-survey-aware`
- `rerun-with-binding`
- `repair-execution`
- `compare-baseline`
- `stop-for-validation`
- `reject-or-redesign`
- `promote-local-review`

Route selection now uses the latest prior action before default routing. For example, a stats run blocked by `blocked_survey_required` routes to `paper-run --backend r-survey` when available; a locally validated ML run stops for validation-design review before stronger claims.
