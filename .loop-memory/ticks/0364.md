Axis: add-primitive
Contribution: methods + research

## Hypothesis
The connector should be judged against reporting and evidence-appraisal standards, not only against whether an API call succeeds.

## Deliverable
Reviewed current external guidance and encoded its implications into the loop:
- TRIPOD+AI: prediction evidence should expose calibration, discrimination, intended use, and validation boundary.
- STARD: diagnostic evidence should expose index test, reference standard, thresholds, intended use, and sources of bias/variation.
- GRADE/ACIP: evidence certainty depends on study design and risk-of-bias appraisal; observational evidence should not silently become strong clinical evidence.

## Verification
No code change in this tick. These principles were used to evaluate whether literature context should supply planning signals and QA warnings rather than factual authority.
