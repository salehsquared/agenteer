# Tick 0214 - Add Primitive / Analysis Benchmark

## Hypothesis

Golden stats and ML routes need a reusable benchmark gate rather than ad hoc JSON inspection in loop memory.

## Scope

- Add an aggregator over the unified analysis manifest surface.
- Support optional local-review-ready gating.
- Keep paper packet benchmarks separate.

## Intervention

Added `research analysis-benchmark --run-dir <dir>* [--require-ready] [--json]`.

It builds manifests for each run directory and returns pass/fail, summary, per-manifest readiness, and next action.
