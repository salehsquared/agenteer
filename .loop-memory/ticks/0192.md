# Tick 192 - question-the-question - modeling-plan as the analysis front door

## Axis

Question-the-question / UX / architecture.

## Question

Should Agenteer add a new analysis front-door command, or should the existing `modeling-plan` become the front door?

## Answer

Use `modeling-plan`. It already combines question classification, method ontology, ML registry, workflow policies, and data evidence. Adding another command would increase the maze called out in Tick 191.

## Deliverable

Added `routeRecommendation` to `ModelingDecisionPlan`:

- `paper-run` for complex-survey inference
- `stats-run` for executable standard-table statistical methods
- `ml-run` for prediction/classification/clustering/dimensionality reduction
- `method-select` when a method still needs AnalysisSpec promotion
- `stop-for-review` for blocked or unsupported cases

The human renderer now shows the route, and `nextAction` is the recommended next command when available.

Saved CLI smoke evidence at `.loop-memory/modeling/0192-route-recommendation.json`.
