# Tick 177 - remove-or-merge - lifecycle absorbs rerun stability

## Axis

Remove or merge / reviewer UX.

## Deliverable

Merged rerun-stability status into the existing `research paper-lifecycle` summary rather than creating another reviewer-facing status command. Lifecycle now reads `rerun-stability.json` when present and surfaces:

- status: `pass`, `fail`, or `not_checked`
- summary
- artifact path

A failed rerun-stability artifact blocks local review. A missing artifact remains advisory for local review but changes the next action to recommend rerun stability before archive or benchmark promotion.

The real fasting-subsample paper now has lifecycle output showing:

- lifecycle: `ready_for_local_review`
- rerun stability: `pass`
- summary: 15/15 rerun stability checks passed
