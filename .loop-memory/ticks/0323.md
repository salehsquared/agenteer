# Tick 0323 - Nested Evidence Ingestion For Trust-Layer Inspection

Axis: cross-domain.
Contribution: `truth, QA, reproducibility`.

## Hypothesis

If unified run inspection treats a packet like a legal discovery bundle with nested exhibits rather than a flat folder, then existing golden packets with `analysis-run/stats-run/*` artifacts will be inspected correctly.

## Scope

Harden only the new trust-layer evidence ingestion and regression tests. Do not add another CLI command or alter existing golden artifacts.

## Intervention

Hardened the research trust layer evidence collector so canonical JSON/Markdown artifacts are resolved from nested run directories when the packet root does not contain a flat artifact. Added source-path tracking so paper paths, QA paths, stats-run evidence, and report references point at the actual nested file.

## Evidence

Before: `run-inspect` on `.loop-memory/golden/0229-diagnostic-threshold-route` reported unknown run kind, missing paper QA, no paper path, no missingness diagnostics, and no complete-case N.

After manual smoke:

```json
{
  "readiness": "needs_methods_review",
  "paperQa": "pass",
  "rerun": "pass",
  "paper": true,
  "kind": "stats-run",
  "n": 180,
  "warnings": 2
}
```

Regression test added: nested analysis-run packet root now resolves nested `paper.md`, `paper-qa.json`, `stats-run.json`, `diagnostics.json`, `stats-qa.json`, and `rerun-stability.json`.

Verification:

- `npm run build --workspace @agenteer/cli`
- `npm test -- packages/cli/tests/research-trust.test.ts`
- Manual CLI smoke: `node packages/cli/dist/bin/agenteer.js research run-inspect --run-dir .loop-memory/golden/0229-diagnostic-threshold-route --json`

## Verification

Passed build, targeted trust-layer test suite, and the manual diagnostic golden packet `run-inspect` smoke.

## Decision

Promotion decision: `promote`. This directly improves the new trust-layer golden path and prevents false missing-artifact warnings on real packet roots.

## Counter-Design Considered

Rejected requiring callers to pass the deepest `stats-run` directory. Operators reasonably inspect packet roots, and requiring deep paths would preserve the very artifact sprawl this layer is meant to reduce.
