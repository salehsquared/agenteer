# Tick 0327 - Collapse Nested Benchmark Cases

Axis: remove-or-merge.
Contribution: `QA, reproducibility, UX`.

## Hypothesis

If continuous benchmark discovery collapses nested runner directories under packet roots, then benchmark evidence will describe research packets rather than double-counting implementation internals.

## Scope

Harden `benchmark-suite-run` discovery and verify it against the diagnostic golden route. No new CLI surface.

## Intervention

Updated benchmark run discovery to collect candidate run directories, sort by path depth, and remove child directories when an ancestor is already a benchmarkable packet. Added a regression test proving a nested `analysis-run/stats-run` folder counts as one packet case, not two.

## Evidence

Before manual smoke on `.loop-memory/golden/0229-diagnostic-threshold-route`:

- `caseCount`: 4.
- Cases included both parent `analysis-run` packet directories and child `stats-run` directories.
- Child stats-run cases created duplicate low-score regressions because they lacked root-level paper artifacts by design.

After:

```json
{
  "caseCount": 2,
  "meanScore": 0.7375,
  "cases": [
    { "id": "analysis-run", "score": 0.7375, "warnings": 1 },
    { "id": "analysis-run-repeat", "score": 0.7375, "warnings": 1 }
  ],
  "regressions": []
}
```

Saved smoke artifacts under `.loop-memory/golden/0327-trust-benchmark-smoke/`.

## Verification

- `npm run build --workspace @agenteer/cli`
- `npm test -- packages/cli/tests/research-trust.test.ts`
- `npm test -- packages/cli/tests/research-machine.test.ts packages/cli/tests/research-trust.test.ts packages/cli/tests/research-ml.test.ts`
- Full `npm test`: 55 files, 388 tests passed.
- Manual CLI smoke: `research benchmark-suite-run --suite .loop-memory/golden/0229-diagnostic-threshold-route --out-dir .loop-memory/golden/0327-trust-benchmark-smoke --json`

## Decision

Promotion decision: `promote`. This removes duplicate benchmark noise and makes continuous benchmark output closer to the user's mental model of packet-level review.

## Counter-Design Considered

Rejected keeping child `stats-run` directories as separate benchmark cases. That is useful for runner-level debugging, but `benchmark-suite-run` is a packet-level trust gate and should not double-count internal folders.
