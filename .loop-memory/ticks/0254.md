# Tick 0254 - More Robust - Exploration To Planning

## Scope

Label: `truth`, `methods`, `UX`.

## Hypothesis

If `modeling-plan` consumes `exploration-handoff` artifacts directly, exploratory NHANES findings become less fragile because the planner preserves the source exploration hash, clearance level, blocker list, review note, question seed, target seed, and table evidence instead of relying on manual flag copying.

## Intervention

- Added `explorationHandoff` to the modeling decision request schema and plan output.
- Added `agenteer research modeling-plan --exploration-handoff <handoff.json>`.
- The CLI now reads `modelingPlanSeed.question`, `modelingPlanSeed.outcome`, and `modelingPlanSeed.tablePath` from a handoff when explicit flags are absent.
- Held handoffs emit `EXPLORATION_HANDOFF_METHODS_REVIEW`; held handoffs without a methods-review note block planning; blocked/stop handoffs block planning.
- Text rendering now shows exploration handoff status and clearance.
- Added regression coverage for reviewed versus unreviewed held handoffs.
- Documented the handoff-to-modeling path.

## Decision

Promote. This removes manual copy/paste between exploration and planning and strengthens the actual-data golden path.
