# Tick 367: literature-aware pre/post modeling

Axis: faster-simpler
Contribution: planning + methods

## Hypothesis
The analysis runner should not ignore literature during the initial route decision, and the post-run plan should preserve the same evidence context.

## Deliverable
`researchAnalysisRunCommand` now derives a literature context before the initial modeling plan and carries local context evidence into the post-run modeling plan.

## Verification
Regression tests assert both `result.modelingPlan.literatureEvidence.source` and `result.postRunModelingPlan.literatureEvidence.source` are `literature-context`.

## Counter-Design Considered
Rejected only attaching literature after report generation because it would make route selection blind to evidence signals.
