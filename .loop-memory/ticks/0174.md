# Tick 174 - question-the-question - paper versus safety artifact

## Axis

Question the research question / clinician UX.

## Deliverable

Questioned whether a polished generated paper is the right first artifact for a clinician-reader. Kept the paper, but changed its first visible block: `research paper-run` now generates a standardized `Local Review Safety Header` before the abstract.

The header states:

- analysis type
- survey method
- weight domain
- population
- causal status
- clinical actionability status
- human review requirement

`paper-qa` now requires this header for paper-run evidence and blocks missing headers as critical. The real fasting-subsample paper was regenerated and passes the new safety-header check.
